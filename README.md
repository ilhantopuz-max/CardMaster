# CardMaster
Kartvizit OCR (Gemini) – Android. Fotoğraf → OCR → onay ekranı → veritabanı + rehber.

## APK nasıl alınır
1. GitHub'da yeni repo aç, bu klasörün TÜM içeriğini (gizli `.github` klasörü dahil) yükle.
2. Actions sekmesi → "Build APK" otomatik çalışır (~5-8 dk).
3. Sağdaki **Releases** bölümünden `CardMaster.apk` indir, telefonda kur.
4. Uygulamada ⚙ Ayarlar'dan Gemini API anahtarını gir.
